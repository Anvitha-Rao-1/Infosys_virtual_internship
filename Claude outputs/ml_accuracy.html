Sprout — Forecast Accuracy, by Target

Real backtest results from the project's own evaluation run (evaluate_forecast.py / evaluate_habit_forecast.py). Each bar is the accuracy of whichever model actually won that series' backtest — not one fixed algorithm.

⚠️ These evaluation runs report only the winning model's numbers per series — not a side-by-side of all three candidates (Linear Regression / ARIMA / XGBoost) for every target. So this chart shows "how accurate was the model Sprout ended up using," not "how did each of the three algorithms individually score." If you want the full three-way comparison, that would need re-running evaluate_forecast.py with per-candidate metrics printed.
